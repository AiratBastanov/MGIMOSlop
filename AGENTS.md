# Работа с проектом «Цифровой деканат»

Это конкурсный прототип на вымышленных данных. Начните с README.md, docs/SETUP.md и docs/ARCHITECTURE.md. Сообщения, документация и интерфейс — на русском.

- Сохраняйте Django/PostgreSQL и React/TypeScript/Vite, действующие миграции, учебную историю и действия пользователей. Не заполняйте БД при старте или чтении страницы.
- Проверяйте владельца, роль и аудиторию на сервере. Используйте существующие сервисы для заявок, материалов, уточнений и публикаций. Результат работы не является официальной оценкой.
- Поиск читает разрешённые проекции без операций. Подготовка принадлежит студенту; служба получает только неизменный отправленный снимок. Записи на консультации сохраняются атомарно с историей и уведомлениями; импорт не меняет их статус.
- Секреты, локальная конфигурация, пароли, файлы БД и приватные вложения не входят в Git. Используйте только синтетические данные.
- Помощник работает со справкой и разрешёнными темами. Не давайте модели доступ к личным записям и операциям. Работа приложения не зависит от наличия модели.
- Сохраняйте немодальные панели, пять мобильных разделов, текстовые статусы и контекст сеанса. Не добавляйте декоративные стрелки или chevrons.
- Проверяйте затронутое поведение и зависимости по docs/VALIDATION.md. Браузерные проверки с изменениями выполняйте только на отдельном демо; не сбрасывайте рабочие данные.
- Git push, размещение сайта, внешняя почта и изменение видимости требуют разрешения для соответствующего задания. Указание репозитория само по себе не разрешает будущие операции.
- Публичное дерево собирается по scripts/publication-files.json. Полная история разработки и закрытые результаты проверок хранятся отдельно; эта выборка не выдаётся за исходную историю.
